Core design features we emphasized:

Our app focuses on the ingredient fit feature that was identified as having the highest feasibility and potential impact. The first thing you do is submit what ingredients you have. This orients the user to the idea that their ingredients will be matched with a recipe. For each recipe displayed, the user can see how many ingredients they have and how many are missing. If they click show on the missing ingredients, they can see the proposed swaps or necessary ingredients. These swaps continue to follow the user into the expanded recipe card and the recipe preparation screens. Within the favorite recipes, there is a filter to show recipes that only contain the ingredients the user has.
